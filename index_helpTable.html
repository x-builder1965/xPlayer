🎬 プレイメディアパネル
　・動作モード切替 🎬／🔄️ Ctrl+v なし ・xPlayerの動作を視聴モード（青）／変換モード（赤）。（再生・変換中は無効）
　・カット編集 ✂️ Ctrl+e なし ・カット編集モードの開始（青）／終了（赤）。
　・動画結合 🎞️ Ctrl+j なし ・プレイリスト内の動画を結合。
　・再生中メディアパス Text Box Ctrl+g Click ・プレイリストパネルの表示／非表示を切り替えます。
　・ランダム再生 🔀 Ctrl+r なし ・プレイリスト内のメディアをランダムに再生。🔀（青）：通常再生／🔀（赤）：ランダム再生。
　・繰り返し再生 🔁／🔂 Ctrl+Shift+r なし ・プレイリスト内のメディアを繰り返し再生。🔁（青）：繰返無効／🔁（赤）：全メディア繰返／🔂（黄）：１メディア繰返。
　・自動シャッフル設定 🤖 Ctrl+w なし ・ランダム再生・全繰り返し再生中に自動でシャッフルする機能の有効（赤）・無効（青）を設定。
📚 プレイリストパネル
　・フィルタ条件入力 Text Box なし なし ・フィルタ条件にスペース区切り（AND）、カンマ区切り（OR）で複数語句を入力。

　・プレイリスト並び替え 📩 Shift+m Popup Menu ・プレイリストを並び替え（（なし）／ファイル▲／ファイル▼／種類▲／種類▼／作成日時▲／作成日時▼／（ランダム））。
　・プレイリスト表示形式変更 📚 Shift+l Popup Menu ・プレイリストの表示形式を変更（リスト／サムネイル＋リスト／サムネイル小・中・大）。
　・プレイリスト編集 上へ移動 🔼 Shift+p なし ・プレイリストの選択メディアを上へ移動。
　・プレイリスト編集 下へ移動 🔽 Shift+n なし ・プレイリストの選択メディアを下へ移動。
　・プレイリスト編集 メディア追加 ＋ Shift+a Popup Menu ・プレイリストの選択位置に選択したメディアファイル・プレイリスト内のメディアを追加。
　・プレイリスト編集 メディア削除 － Shift+d なし ・プレイリストの選択位置のメディアを削除。
　・プレイリスト編集 クリア 🆑 Shift+c なし ・プレイリストの全メディアをクリア。
　・プレイリスト編集 保存 💾 Shift+s なし ・プレイリストを名前をつけて保存。
　・プレイリスト List なし Click／Double Click ・クリック：プレイリスト内のメディアを選択。／ダブルクリック：選択したメディアを再生。

⚙️ 設定パネル
　・フルスクリーン表示／解除 🖥️ Ctrl+a Double Click ・プレイヤーのフルスクリーン表示（青）またはウィンドウ表示（赤）を切り替える。

　・イメージエフェクト＆BGM設定 💃 Ctrl+b Popup Menu ・画像再生時のトラジションエフェクトの切替および再生BGMの設定。
　・コントロール制御 👁️ Ctrl+y Popup Menu ・コントロールパネル自動表示抑止、センターコントロール無効の設定・解除
　・設定インポート・エクスポート 🍥 Ctrl+i／Ctrl+o popup menu ・プレイヤーの設定をインポートし画面を復元またはエクスポートする。
　・設定モード終了 ❌ Ctrl+q なし ・設定モードの終了。

　・ズームモード終了 ❌ Ctrl+z なし ・ズームモードの終了。
