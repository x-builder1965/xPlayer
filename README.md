# xPlayer - メディアプレイヤー - (xPlayer-windows)

## 概要
xPlayer は **ローカル動画・音声・画像の再生および簡易編集** に特化した Electron ベースのマルチメディアプレイヤーです。  
幅広いフォーマットに対応しており、プレイリスト管理、再生速度変更、カット編集、動画結合、デジタルズーム、音声/字幕トラック切り替えなどの機能を備えています。  
※ Web上の動画（YouTube / Twitch / 各種URL）は、外部ブラウザ（Chrome または Edge）でポップアップ再生できます。

> **Note:** 変更履歴は、アプリ内のヘルプ（❔）下部の「変更履歴」をご参照ください。

---

## 主な機能

- **📁 ローカル動画・音声再生**  
  - フォルダ・ファイル選択 / ドラッグ＆ドロップ / エクスプローラーからのダブルクリック（関連付け）による再生に対応  
  - プレイリストファイル（`.amppl`）の読み込みに対応  
  - **対応フォーマット:**  
    - 動画：`mp4`, `mkv`, `webm`, `avi`, `flv`, `mov`, `wmv`, `mpg`, `mpeg`, `ts`, `mts`, `m2ts`, `vob`, `ogv`, `3gp`, `m4v`, `asf`  
    - 音声：`mp3`, `wav`, `flac`, `ogg`, `oga`, `m4a`, `aac`, `opus`, `wma`, `aiff`, `aif`, `alac`, `ape`
    - 画像： `jpg`, `jpeg`, `png`, `gif`, `bmp`, `tiff`, `webp` など  
  - HTML5 ネイティブ再生に対応する形式（`mp4`, `webm`, `ogg`, `mov`, `m4v`, 一部 `mkv`）はダイレクト再生  
  - 非対応形式は **FFmpeg** により自動変換（日本語音声・字幕を優先取得）

- **▶️ 再生制御**  
  - 基本操作（再生 / 一時停止 / 停止 / 30秒送り・戻し / 前後トラック移動）  
  - シークバーおよびマウスの左右ドラッグによる再生位置移動  
  - 再生速度変更（0.25× 〜 5.0×）  
  - ランダム再生（🔀）/ 繰り返し再生（🔁 全件・🔂 1件・オフ）  
  - 各種再生設定の自動保存・復元

- **📚 プレイリスト管理**  
  - 独自プレイリスト（`.amppl`）の作成・編集・保存・読み込み  
  - フォルダ追加時の再帰読み込み（サブフォルダ含む）に対応  
  - アイテムの追加・削除・並び替え（手動ドラッグ / ファイル名 / 種類 / 作成日時 / ランダム）  
  - 豊富な表示スタイル（リスト、サムネイル＋リスト、サムネイル小・中・大）  
  - 高機能フィルタ検索（AND検索：スペース区切り / OR検索：カンマ区切り）と該当件数表示  

- **🌐 ネットURL再生**  
  - YouTube / Twitch などの URL を Chrome または Edge 経由で外部再生  
  - クリップボード内の URL を自動検知してポップアウト再生

- **✂️ カット編集**  
  - 不要部分を複数指定して削除・結合保存  
  - IN/OUT マーク指定、編集タイムライン、フレーム単位の微調整  
  - 高速モード（ストリームコピー）と再エンコードモードの自動判定  
  - 出力フォーマット：`mp4`（保存先・ファイル名指定可）

- **🎞️ 動画結合**  
  - プレイリスト内の複数動画を1つのファイルに結合  
  - 動画の FPS を自動検出し、最適な出力 FPS を決定して統一変換・結合

- **🔍 ズーム＆表示調整**  
  - デジタルズーム（-100% 〜 +500%）＆ マウスドラッグによるパン（移動）操作  
  - マウスホイール / `Ctrl + ↑↓` で拡縮、`Ctrl + 0` でリセット  
  - アスペクト比切り替え（4:3、16:9、18:9、21:9、9:21）  
  - 描画モード変更（含む / 覆う / 満たす）  
  - 現在再生中フレームのスナップショット撮影（Windows Snipping Tool 連携）

- **⚙️ 設定**  
  - 背景壁紙・オーディオビジュアル（audioMotion）のカスタマイズ  
  - コントロールパネル・プレイメディアパネルの自動表示抑止機能  
  - 常に最前面表示 / フルスクリーン切り替え  
  - 設定データのインポート・エクスポート機能  

- **その他**  
  - プレイヤーの操作状況・プレイリスト・各種設定は終了しても保持され次回起動時に復元  

> **Note:** 機能詳細・ショートカット対応はアプリ内のヘルプ（❔）を参照ください。

---

## 注意事項
- **多重起動について:** 
  - プレイヤーの多重起動は可能ですが、最初に起動したプレイヤーの設定値のみ保持されます。  
  - 多重起動時、プレイヤーのコントロールパネルの表示名には 🚫 マークが表示されます。

## 動作環境
- **OS:** Windows 10 / 11（x64 推奨）
- **配布版:** Electron パッケージ済み（Node.js の事前インストールは不要）
- **開発環境:** Node.js 18+ / npm

## インストール・起動

### ソースコードから開発・ビルドする場合
※ 事前に Node.js（npm含む）および Git のインストールが必要です。

```bash
# リポジトリのクローンと依存関係のインストール
git clone <repository-url>
cd xPlayer
npm install

# 開発モードで起動
npm start

# アプリのビルド・パッケージング
npm run dist           # x64 向け最大圧縮ビルド
npm run build          # Windows インストーラー生成（dist-win/ に出力）
npm run dist:portable  # ポータブル版 (.exe) の生成
npm run sign           # 署名付きビルド（環境変数 CSC_KEY_PASSWORD が必要）
```

### インストーラーから実行する場合
1. リリースまたは `dist-win/` フォルダー内の `xPlayer Setup X.X.X.exe` を実行してインストールします。
2. デスクトップまたはスタートメニューから起動してください。  
   ※ メディアファイル（`.mp4`, `.mp3` 等）や `.amppl` ファイルのダブルクリック起動・関連付けにも対応しています。
