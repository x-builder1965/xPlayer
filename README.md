# xPlayer -メディアプレイヤー- (xPlayer-windows)

## 概要
xPlayer は **ローカル動画の再生・編集、音声再生** に特化した Electron ベースのマルチメディアプレイヤーです。  
幅広い動画・音声形式に対応し、プレイリスト管理、再生速度変更、カット編集、動画結合、ズーム、音声／字幕トラック選択などを搭載しています。  
ネット動画（YouTube / Twitch / その他URL）は外部ブラウザ（Chrome 推奨）でポップアップ再生します。

**変更履歴はヘルプ（❔）下部の「変更履歴」を参照**

## 主な機能
- **📁 ローカル動画・音声再生**  
  - フォルダ選択（📁）／ファイル選択（🗒️）／ドラッグ＆ドロップ／エクスプローラーから動画ファイルやプレイリスト（.amppl）をダブルクリックして再生可能  
  - 動画：mp4, mkv, webm, avi, flv, mov, wmv, mpg, mpeg, ts, mts, m2ts, vob, ogv, 3gp, m4v, asf  音声：mp3, wav, flac, ogg, oga, m4a, aac, opus, wma, aiff, aif, alac, ape などをサポート  
  - HTML5 ネイティブ再生が可能な動画形式（mp4, webm, ogg, mov, m4v, 一部 mkv）はそのまま再生  
  - 非対応形式は **FFmpeg** による mp4 変換を実行し、日本語音声・字幕を優先して扱います

- **▶️ 再生制御**  
  - 再生（▶️）／一時停止（⏸️）／停止（⏹️）／30秒送り戻し（⏩⏪）／前後動画移動（⏭️⏮️）  
  - シークバーまたは左右マウスドラックで再生位置移動可能  
  - 再生速度変更（0.25×〜5.0×）  
  - ランダム再生（🔀）／繰り返し再生（🔁 全動画・🔂 1動画・無効）  
  - 設定はアプリ再起動後も保持

- **📚 プレイリスト管理**  
  - プレイリスト（.amppl形式）の作成・編集・保存・読み込み  
  - ファイル選択、フォルダ選択（再帰対応）での読み込み可能  
  - 再生順変更・動画追加／削除・上下移動 　
  - 並び替え（パス順・作成日時順・ランダム）  
  - 表示形式（リスト・サムネイル＋リスト・サムネイル小・中・大）  
  - フィルタ条件検索（スペース区切り（AND）、カンマ区切り（OR）条件指定対応）  
  - プレイリストのフィルタ検索結果件数表示  

- **🌐 ネット動画再生**  
  - YouTube / Twitch / そのほかの URL を Chrome で外部再生  
  - クリップボードの URL を自動ポップアウト再生

- **✂️ カット編集**  
  - 複数範囲の不要部分を削除して残りを結合保存  
  - IN/OUT マーク設定、編集タイムライン、フレーム単位の微調整  
  - 高速モード（ストリームコピー）／再エンコードモードを自動判別  
  - 出力形式は mp4（保存先やファイル名を選択可能）

- **🎞️ 動画結合**  
  - プレイリスト内の複数動画を結合  
  - FPS を自動検出し、多数決で結合時の出力 FPS を決定  
  - 統一フォーマットに変換してから結合

- **⚙️ 設定機能**  
  - 背景壁紙の設定変更  
  - オーディオモーションの設定変更  
  - フルスクリーンの設定変更  
  - 画面の常に前面表示の設定  
  - 設定のインポート・エクスポート機能  

- **🔍 ズーム＆移動**  
  - -100%〜+500% のデジタルズーム  
  - マウスドラッグでパン  
  - ホイール／Ctrl+↑↓ で拡大／縮小変更、Ctrl+0 でリセット  
  - アスペクト比「4:3、16:9、18:9、21:9、9:21」の変更設定  
  - 描画モード（含む、覆う、満たす）の変更設定  
  - 動画切り替えや再起動時もズーム状態を記憶  
  - 現在再生中のフレームを Windows Snipping Tool でスナップショット撮影  

- **その他**  
  - 機能（ショートカット）・変更履歴の詳細はヘルプ（❔）を参照  

## 注意事項
  - プレイヤーの重複起動は可能ですが後で起動したアプリの設定保存は制限されます。  
  - 重複起動時は後で起動したアプリのアプリ名の前に🚫を表示。  

## 動作環境
- Windows 10 / 11（x64 推奨）
- 配布版は Electron でパッケージング済み（Node.js 不要）
- 開発時は Node.js 18+ / npm が必要
- ビルド済み出力は `dist-win/` フォルダーに配置

## インストール・起動
1. `dist-win/` フォルダー内にある `xPlayer Setup 4.17.2.exe` などからインストール  
2. インストール後、デスクトップまたはスタートメニューから起動  
   - 動画ファイル（.mp4 など）やプレイリスト（.amppl）をダブルクリックして再生可能

### 開発・ビルド（ソースから）
※Node.js（npm含む）、Gitのインストール必須
```bash
git clone <repository-url>
cd xPlayer-windows
npm install
npm start              # 開発実行
npm run dist           # x64 の最大圧縮ビルド
```
他のビルド方法
```bash
npm run build          # Windows インストーラー生成（dist-win に出力）
npm run dist:portable  # ポータブル版生成
npm run sign           # authenticode.pfx を使って署名（環境変数 CSC_KEY_PASSWORD が必要）
```
