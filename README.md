# xPlayer - メディアプレイヤー - (xPlayer-windows)

xPlayer は、Windows で動画・音声・画像を「すぐ開いて」「手軽に楽しむ」ためのマルチメディアプレイヤーです。  
ローカルファイルの再生に特化しつつ、プレイリスト管理、再生速度調整、カット編集、結合編集、ズーム調整、音声/字幕の扱いなど、日常の視聴や簡単な編集に便利な機能を備えています。

> **Note:** 変更履歴は、アプリ内のヘルプ（❔）下部の「変更履歴」をご参照ください。

## まずはこれだけ

1. 使いたいメディアファイルを選ぶ
2. 再生したいファイルをドラッグ＆ドロップするか、ファイル選択を行う
3. 再生・速度調整・編集・プレイリスト管理などを利用する

> Web上の動画（YouTube / Twitch / 各種URL）は、外部ブラウザ（Chrome または Edge）でポップアップ再生できます。

## こんな場面に便利です

- 家族の動画を気軽に再生したい
- 音楽や音声ファイルをBGMのように使いたい
- 画像をスライド表示しながら鑑賞したい
- 不要な部分だけを切り出して簡単に編集したい
- まとめて再生したいファイルをプレイリストにしたい

## 主な機能

- **📁 ローカルメディア再生**  
  - フォルダ・ファイル選択 / ドラッグ＆ドロップ / エクスプローラーからのダブルクリック（関連付け）による再生に対応  
  - プレイリストファイル（`.amppl`）の読み込みに対応  
  - **対応フォーマット:**  
    - 動画：`mp4`, `mkv`, `webm`, `avi`, `flv`, `mov`, `wmv`, `mpg`, `mpeg`, `ts`, `mts`, `m2ts`, `vob`, `ogv`, `3gp`, `m4v`, `asf`  
    - 音声：`mp3`, `wav`, `flac`, `ogg`, `oga`, `m4a`, `aac`, `opus`, `wma`, `aiff`, `aif`, `alac`, `ape`, `m4b`, `mid`, `midi`  
    - 画像：`jpg`, `jpeg`, `png`, `gif`, `bmp`, `tiff`, `webp` など  
  - HTML5 ネイティブ再生に対応する形式（`mp4`, `webm`, `ogg`, `mov`, `m4v`, 一部 `mkv`）はダイレクト再生  
  - 非対応形式は **FFmpeg** により自動変換（日本語音声・字幕を優先取得）

- **▶️ 再生制御**  
  - 基本操作（再生：▶️ / 一時停止：⏸️ / 停止：⏹️ / 30秒送り・戻し：⏪⏩ / 前後トラック移動：⏮️⏭️）  
  - シークバーおよびマウスの左右ドラッグによる再生位置移動  
  - 再生速度変更（0.25× 〜 5.0×）  
  - ランダム再生（🔀）/ 繰り返し再生（🔁 全件・🔂 1件・オフ）  
  - 各種再生設定の自動保存・復元  
  - 画面中央にセンターコントロール（前へ：⏮️、再生／一時停止：▶️／⏸️、次へ：⏭️）を表示

- **📚 プレイリスト管理**  
  - 独自プレイリスト（`.amppl`）の作成・編集・保存・読み込み  
  - フォルダ追加時の再帰読み込み（サブフォルダ含む）に対応  
  - アイテムの追加・削除・並び替え（ファイル名 / 種類 / 作成日時 / ランダム）  
  - 豊富な表示スタイル（リスト、サムネイル＋リスト、サムネイル小・中・大）  
  - 高機能フィルタ検索（AND検索：スペース区切り / OR検索：カンマ区切り）と該当件数表示  

- **🌐 ネットURL再生**  
  - YouTube / Twitch などの URL を Chrome または Edge 経由で外部再生  
  - クリップボード内の URL を自動検知してポップアウト再生

- **✂️ カット編集**  
  - 不要部分を複数指定して削除・結合保存  
  - IN/OUT マーク指定、編集タイムライン、フレーム単位の微調整  
  - 高速モード（ストリームコピー）と再エンコードモードの自動判定  
  - 出力フォーマット：動画：`mp4`、音声：`mp3`

- **🎞️ 結合編集**  
  - プレイリスト内の複数動画または音声を1つのファイルに結合  
  - 動画の FPS を自動検出し、最適な出力 FPS を決定して統一変換・結合しmp4で出力
  - 音声をビットレート 192kbps、サンプリングレート 48kHzで統一変換・結合しmp3で出力

- **🔍 ズーム＆表示調整**  
  - デジタルズーム（-100% 〜 +500%）＆ マウスドラッグによるパン（移動）操作  
  - マウスホイール / `Ctrl + ↑↓` で拡縮、`Ctrl + 0` でリセット  
  - アスペクト比切り替え（4:3、16:9、18:9、21:9、9:21）  
  - 描画モード変更（含む / 覆う / 満たす）  
  - 現在再生中フレームのスナップショット撮影（Windows Snipping Tool 連携）

- **⚙️ 設定**  
  - 背景壁紙の選択  
  - 音声再生時のオーディオモーションの設定  
  - 画像再生時のトランジションエフェクトおよびBGMの設定  
  - コントロールパネル自動表示抑止・センターコントロール無効の設定、解除機能  
  - 常に最前面表示 / フルスクリーン切り替え  
  - 設定データのインポート・エクスポート機能（ドラッグ＆ドロップによるインポート、エクスプローラのダブルクリックで起動可能）  

- **その他**  
  - プレイヤーの操作状況・プレイリスト・各種設定は終了しても保持され次回起動時に復元  

> **Note:** 機能詳細・ショートカット対応はアプリ内のヘルプ（❔）を参照ください。

## 注意事項
- **多重起動について:** 
  - プレイヤーの多重起動は可能ですが、最初に起動したプレイヤーの設定値のみ保持されます。 
  - ただし、多重起動時は手動で設定エクスポート（📤）を使い設定値を保存できます。  
  - 多重起動時コントロールパネルの表示名には 🚫 マークが表示されます。

## インストール・起動

### まずはインストーラーで使う
1. ビルド実施後 `dist-win/` フォルダー内の `xPlayer Setup X.X.X.exe` を実行してインストールします。
2. デスクトップまたはスタートメニューから起動してください。
3. メディアファイルや `.amppl` ファイルをダブルクリックすると、そのままアプリで開けます。

### ソースコードから開発・ビルドする場合
※ 事前に Node.js（npm含む）および Git のインストールが必要です。

```bash
# リポジトリのクローンと依存関係のインストール
git clone <repository-url>
cd xPlayer
npm install

# 開発モードで起動
npm start

# アプリのビルド・パッケージング
npm run build          # Windows インストーラー生成（dist-win/ に出力）
npm run dist           # x64 向け最大圧縮ビルド
npm run dist:32        # 32bit 版ビルド
npm run dist:portable  # ポータブル版 (.exe) の生成
npm run sign           # 署名付きビルド（環境変数 CSC_KEY_PASSWORD が必要）
```
